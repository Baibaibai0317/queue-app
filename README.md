# 趣屿 QUYU v9 云端多人版（待配置）

## 关键区别
本包提供 Supabase 云端接入代码，但**没有你的云端账号/项目密钥，不能自动成为在线多人网站**。配置前会退回本地演示模式。

## 上线步骤
1. 在 https://supabase.com/dashboard 新建项目。
2. 在 **Authentication → Providers → Anonymous Sign-Ins** 启用匿名登录（如界面有变化请查 Supabase 文档）。匿名身份不是可恢复账号，清除浏览器数据可能丢失身份。
3. 打开 **SQL Editor**，复制执行 `schema.sql`。请在新建项目执行；若已有同名表/策略，请先检查冲突。
4. 打开 **Project Settings → API** 或 **Connect**，复制 **Project URL** 和 **publishable / anon key** 到 `cloud-config.js`。**不要填 service_role / secret key**。
5. 将整个文件夹发布到 Netlify Drop 等静态托管。务必用 https 网址测试，勿用 file:// 本地文件验证云端功能。
6. 在两台不同设备打开同一个公开网址：A 发笔记，B 等待约 4 秒看更新；A 点赞，B 约 4 秒后看到数字变化。评论同理。

## 已实现
- 新发布笔记及图片云端共享；云端笔记点赞、取消点赞、评论跨设备同步（每 4 秒轮询）。
- 通过数据库唯一约束保证每个匿名身份每篇笔记只能点一次赞。
- 保留既有欢迎页、兴趣选择、300+ 演示笔记及界面。

## 限制（请务必知悉）
- **原先300多篇预置示例笔记不在云端**，它们的点赞/评论仍是本地演示；只有启用云端后用户新发布的笔记共享。若要预置笔记也跨设备同步，需另做种子数据迁移。
- 评论/发布是共享的；收藏仍为本地演示，尚未实现跨设备收藏同步。
- 消息聊天、关注、活动报名仍为演示，不是实时多人服务。
- 同步采用 4 秒轮询，不是毫秒级 WebSocket 推送；大量用户需要分页、增量同步及限流。
- 公开发布前必须补充内容审核、举报、反垃圾、隐私政策、用户协议和正式账号机制。匿名账号清除浏览器数据后不可恢复。
- 网络断开或 CDN 加载失败时会回退本地模式。
